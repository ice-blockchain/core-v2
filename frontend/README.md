# ion-app

ION mobile app — pnpm monorepo for the React Native app and shared packages.

## Structure

```
apps/
  web/               Next.js 15 (App Router)
  mobile/            React Native 0.84 (bare)
packages/
  ui/                Shared React/RN component primitives
  media-acquisition/ Picker, camera, metadata (stub)
```

## Requirements

- Node 20+
- pnpm 9+
- For mobile: Xcode (iOS) or Android Studio (Android)

## Setup

```bash
pnpm install
```

## Dev

```bash
# All apps in parallel
pnpm dev

# Individual
cd apps/web && pnpm dev          # http://localhost:3000
cd apps/mobile && pnpm start     # Metro bundler
```

## Other commands

```bash
pnpm build          # Build all apps
pnpm type-check     # TypeScript across all packages
pnpm lint           # ESLint across all packages
pnpm format         # Prettier
```

## Mobile — native builds

```bash
cd apps/mobile
pnpm ios      # react-native run-ios
pnpm android  # react-native run-android
```

Native project files (`android/`, `ios/`) are generated by `npx react-native init` or via the RN template — run that once to scaffold them, then commit.
